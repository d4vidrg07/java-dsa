# Java: Data Structures and OOP

Java exercises from my Computer Engineering degree at ULPGC (University of Las Palmas de Gran Canaria). I work at the same level in Java as in Python, and many of these programs are the Java counterparts of the ones in my [Python repository](https://github.com/d4vidrg07/Python).

## Contents (`projects/`)

| File | What it does |
|---|---|
| `BrowserHistory.java` | Browser history with a doubly linked list: visit, back, forward and revisited pages. |
| `LoanRegister.java` | Loan register with a singly linked list: append loans, attend returns while collecting penalties and separate overdue loans. |
| `CheckoutQueue.java` | Supermarket checkout queue (linked queue) that tracks daily sales and can split the queue. |
| `TaskList.java` | Task list with completion and time tracking (time spent and time left). |
| `InterestGroup.java` | Group of members: add, remove, membership check and union of two groups. |
| `IsPalindrome.java` | Checks whether an integer is a palindrome without converting it to a string. |
| `PrimeNumbers.java` | Primality test. |

## Notes

- The linked list classes extend a base container (`ContainerBase` / `BaseContainer`) provided by the course, which is not included here. Only my own code is in this repository.
- `IsPalindrome.java` and `PrimeNumbers.java` are written for an online judge, so their public class is called `Solution`.
